Built for the edit loop with AI agents

"The button in the third card" is easy to say and hard for an agent to find. Annotations tell it exactly where to look.

⌖

Exact source location

Every JSX element gets a file:line:column tag in dev, so the agent opens the right line instead of searching.

▣

Element screenshots

Attach a picture of the element as it looks now. It is saved to disk and handed to the agent with the note.

↗

Three ways to hand off

Paste from the clipboard, let the agent read the queue over MCP, or have it land in the Claude Code prompt box.

✓

Tracks what is done

Notes move from sent to read to done. The settings panel keeps a history with thumbnails.

✎

Your own prompt

Rewrite the fix prompt with placeholders for the count, ids, page URL and JSON. English and Chinese built in.

∅

Zero cost in production

It only runs under vite dev, inside a Shadow DOM that never touches your styles. Builds contain none of it.

Get started in two minutes

Needs Vite 8 or later and Node 20.19 or later. Source locations work with any JSX framework; other pages get CSS selectors.

  1. Install

    npm i -D github:shinelikeamillion/vite-plugin-page-annotator

  2. Add the plugin

    Put it before your framework plugin in vite.config.ts, and add .page-annotator/ to .gitignore.

    import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import { pageAnnotator } from 'vite-plugin-page-annotator';

export default defineConfig({
  plugins: [pageAnnotator(), react()], // pageAnnotator({ lang: 'zh' }) for Chinese
});

  3. Show the toolbar

    Run npm run dev, open the page and press ⌘⇧2 (CtrlShift2 on Windows/Linux). It stays hidden until you do, and remembers.

  4. Annotate

    ⌘+click anywhere (or AltA) to start, then click an element. Write what should change and press Enter. Use ↑ ↓ to pick the parent or child instead.

  5. Send

    Click Send. The notes go to the queue in .page-annotator/, and the fix prompt and screenshots are copied to your clipboard. Then hand them to your agent.

Hand off to your AI agent

Pick whichever fits how you work. They all read the same queue.

Paste it anywhere

After Send, paste into Claude Code, Codex or any chat. In a terminal, ⌘V pastes the prompt and CtrlV the screenshot.

Let the agent read the queue

The package ships page-annotator-mcp, a stdio MCP server with no extra dependencies. Then say "handle the page annotations".

Claude Code · .mcp.json

{
  "mcpServers": {
    "page-annotator": { "command": "npx", "args": ["page-annotator-mcp"] }
  }
}

Codex · ~/.codex/config.toml

[mcp_servers.page-annotator]
command = "npx"
args = ["page-annotator-mcp", "--root", "/path/to/your/project"]
ToolWhat it does
get_page_annotationsReturns the sent notes (JSON and screenshots) and marks them read
mark_annotations_doneMarks the ids the agent handled as done
clear_page_annotationsEmpties the queue, only when you ask
pending→delivered→done

Straight into the prompt box

The page-annotator-inbox plugin watches for sends. Each Send puts the fix prompt into Claude Code's prompt box, after any draft you have, and you press Enter.

claude plugin install page-annotator-inbox --marketplace shinelikeamillion/vite-plugin-page-annotator

Or try it without installing: claude --plugin-dir node_modules/vite-plugin-page-annotator/claude-plugin

Shortcuts

On Windows and Linux, use Ctrl where you see ⌘.

⌘⇧2Show or hide the whole tool (remembered)
⌘+click · AltAStart annotating
Right-click · EscStop annotating
↑ ↓Pick the parent or child element (⌥↑ ⌥↓ once you have typed)
Enter · ⇧EnterSave the note · new line
Drag ⠿Move the toolbar; double-click to reset
Right-click ⠿Settings: language, fix prompt, screenshot default, history
