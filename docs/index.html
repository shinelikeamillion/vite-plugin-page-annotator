        Seamless AI Connection
        
Three Ways to Connect with Claude Code & Codex

        
Whether you want prompts injected straight into your terminal input box, pulled on demand via MCP, or copied to your clipboard—all three read from the same .page-annotator/ queue.

      


      

        
        
        
      


      

        
Auto-fill the Claude Code prompt box on every Send

        
The page-annotator-inbox Claude Code plugin watches .page-annotator/outbox.json. Each time you click Send in the browser, the ready-to-run fix prompt lands directly in your Claude Code prompt box (appended safely after any draft you are typing)—just hit Enter.

        

          
claude plugin install page-annotator-inbox --marketplace shinelikeamillion/vite-plugin-page-annotator

          
        

        
Or inside a Claude Code session run /plugin install page-annotator-inbox --marketplace shinelikeamillion/vite-plugin-page-annotator, or try once without installing: claude --plugin-dir node_modules/vite-plugin-page-annotator/claude-plugin

      


      

        
Native MCP Server for Claude Code & OpenAI Codex

        
The package ships page-annotator-mcp, a zero-dependency stdio MCP server. Once configured, simply tell your agent: "handle the page annotations" (or "按标注改").

        
Claude Code · .mcp.json (in project root)

        


{
  "mcpServers": {
    "page-annotator": { "command": "npx", "args": ["page-annotator-mcp"] }
  }
}

          
        

        
OpenAI Codex · ~/.codex/config.toml

        


[mcp_servers.page-annotator]
command = "npx"
args = ["page-annotator-mcp", "--root", "/absolute/path/to/your/project"]

          
        

        

          
MCP ToolWhat it does

          
get_page_annotationsReturns pending annotations (JSON + element screenshot image blocks) and marks them delivered

          
mark_annotations_doneMarks resolved annotation IDs as done so your browser history updates

          
clear_page_annotationsEmpties the annotation queue (only when explicitly requested)

Paste into any AI chat, terminal, or IDE agent

        
Clicking Send automatically copies both the formatted fix prompt (with file:line:column JSON) and element screenshots to your clipboard. In terminal agents like Claude Code or Codex, ⌘V pastes the text prompt and CtrlV pastes the screenshot image.

        Manual Setup
        
Manual Installation in Two Minutes

        
Requires Vite 8+ and Node.js 20.19+. Source locations work automatically with any JSX/TSX framework (React, Preact, Solid); other pages use CSS selectors.

      

      
    
        
  1. 
          
    Install the dev dependency
    
          
    
            
    npm i -D github:shinelikeamillion/vite-plugin-page-annotator
    
            
          
    
        
    2. 
        
  2. 
          
    Register the plugin in vite.config.ts
    
          
    Place pageAnnotator() before your framework plugin in vite.config.ts, and add .page-annotator/ to .gitignore.
    
          
    

    import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import { pageAnnotator } from 'vite-plugin-page-annotator';

export default defineConfig({
  plugins: [pageAnnotator(), react()], // pageAnnotator({ lang: 'zh' }) for Chinese
});
    
            
          
    
        
    3. 
        
  3. 
          
    Wake up the toolbar
    
          
    Run npm run dev, open your page, and press ⌘⇧2 (CtrlShift2 on Windows/Linux). It stays hidden until you toggle it and remembers your choice.
    
        
    4. 
        
  4. 
          
    Click & annotate elements
    
          
    ⌘+click anywhere (or press AltA) to enter annotation mode, then click an element. Write what should change and press Enter. Use ↑ ↓ to step to parent or child elements.
    
        
    5. 
        
  5. 
          
    Send to Claude Code or Codex
    
          
    Click Send. Your annotations are saved to .page-annotator/, pushed to the Claude Code inbox / MCP server, and copied to your clipboard.

        FAQ
        
Frequently Asked Questions

        
Everything you need to know about integrating Page Annotator with Vite, Claude Code, and OpenAI Codex.

      

      

        

          How does Page Annotator connect seamlessly with Claude Code and OpenAI Codex?
          
It offers three built-in bridges: (1) The page-annotator-inbox Claude Code plugin watches .page-annotator/outbox.json and automatically fills your Claude Code terminal prompt box every time you click Send in the browser; (2) The zero-dependency page-annotator-mcp stdio MCP server lets both Claude Code and Codex call get_page_annotations (including element screenshots) and mark_annotations_done; (3) One-click clipboard copy for pasting anywhere.

        

        

          Does this plugin add any overhead to my production bundle?
          
Zero. Both the JSX source-location transform and the in-page UI script use Vite's apply: 'serve' hook. During vite build, the plugin is completely inactive—no data-loc attributes and no client scripts are included in production builds.

        

        

          Which frameworks support exact file:line:column source locations?
          
Any framework that uses JSX or TSX (React, Preact, Solid, Qwik, etc.) gets automatic data-loc="file:line:column" tags powered by Vite 8's native parseAst. Non-JSX apps (Vue, Svelte, plain HTML) also work seamlessly and fall back to specific CSS selectors.

        

        

          Will saving annotations or screenshots trigger unwanted Vite hot-reloads?
          
No. The plugin automatically adds **/.page-annotator/** to Vite's server.watch.ignored list, so writing queue updates and element screenshots to disk never triggers a page reload.
